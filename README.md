# 汝禾姐的一件小事闭环

这是“一件小事审核系统”的可运行原型，包含三个阶段：

1. 早上定事：输入一件小事，按六个检查点审核。
2. 晚上复盘：填写执行结果、好坏、反馈、改进和固化方法。
3. 历史记录：查看行动轨迹并导出 JSON 备份。

## 审核口径

- 具体动作
- 数量标准
- 当天可完成
- 完成物
- 检查点
- 反馈方式

审核通过后才能进入执行。未通过时，系统会指出具体缺项，并用结构化字段帮助用户生成修改版。

## 当前版本的边界

- 数据只保存在当前浏览器，适合个人试用和流程验证。
- 审核是确定性规则，不需要联网，也不会把内容上传到外部服务器。
- 多人同步、管理员后台、真正的 AI 语义判断和微信小程序发布，需要下一阶段增加云端数据库、登录与 AI 接口。

## 打开方式

直接打开 `index.html` 即可。若需要安装到手机桌面或离线使用，请通过本地或线上 HTTP 服务打开。
