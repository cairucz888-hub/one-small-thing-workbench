# 汝禾姐的一件小事工作台

这是“一件小事工作台”的可运行原型，包含三个阶段：

1. 确定今天：一次回答一个问题，用 5 个问题生成今天的一件小事。
2. 做完复盘：填写做到什么、没做到什么、新卡点和改进办法。
3. 成长记录：查看行动轨迹，并把“明天只改一个点”保存成跨天线索。

明日线索不会在复盘完成后立刻打断当天流程。它最早在第二天出现，并且只能带回第 1 问重新判断，不能直接跳过目标和卡点。

## 五个问题

1. 今天结束时，最希望推进哪件事？
2. 现在挡住结果的最大卡点是什么？
3. 今天愿意用多长时间，完成什么最小动作？
4. 做完后留下什么看得见的结果？
5. 从哪里获得真实反馈？

## 审核口径

- 具体动作
- 数量标准
- 当天可完成
- 完成物
- 检查点
- 反馈方式

五个回答会被组合成一条完整的小事，并按六项标准审核。审核通过后才能进入执行。

## 当前版本的边界

- 数据只保存在当前浏览器，适合个人试用和流程验证。
- 当前版本用确定性规则模拟 AI 引导，不需要联网，也不会把内容上传到外部服务器。
- 这一版的目的，是先验证“5 问是否能帮用户找到目标”和“改进点能否接到第二天”。
- 多人同步、管理员后台、真正的 AI 语义判断和微信小程序发布，需要下一阶段增加云端数据库、登录与 AI 接口。
